THE MID NIGHT CAFE WEBSITE

FILES
- index.html: Main website page.
- style.css: Layout, colors, typography, and mobile responsive styles.
- script.js: Small JavaScript enhancement for the current year.

HOW TO OPEN
1. Extract this ZIP file to a folder.
2. Open index.html in a modern web browser.
3. An internet connection is needed for the Google Maps cafe photo, embedded map, and Google Fonts.

The phone number, address, rating, and review count are based on the cafe listing shared by the user. Opening directions and calling use the visitor's device or browser.
